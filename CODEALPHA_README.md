## 📁 Projects

### 🏧 Task 1 — Calculator
**File:** `Calculator.html`

Ek sleek glassmorphism-style calculator with smooth animations aur keyboard support.

**Features:**
- Basic arithmetic — add, subtract, multiply, divide
- Percentage `%` aur sign toggle `±`
- Backspace button
- Expression history display
- Ripple click effect
- **Keyboard fully supported** (0–9, operators, Enter, Escape, Backspace)
- Division by zero handled gracefully
- Chained operations (e.g. 5 + 3 × 2)

**Tech:** Pure HTML + CSS + Vanilla JS — zero dependencies

---

### 🖼️ Task 2 — Image Gallery
**File:** `Image_gallery.html`

Masonry-layout image gallery with category filtering aur full lightbox viewer.

**Features:**
- Masonry grid layout (auto-columns)
- Category filters — All, Nature, City, Abstract, Wildlife
- Hover overlay with image title + category badge
- Lightbox with prev/next navigation
- Keyboard navigation (← → Arrow keys, Escape to close)
- Live photo count badge
- Smooth animations on filter change
- Fully responsive (mobile mein 2-column)

**Tech:** Pure HTML + CSS + Vanilla JS — zero dependencies
